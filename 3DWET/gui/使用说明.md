# 3DWET 网格编辑器 使用说明

## 概述

3DWET 网格编辑器是基于 GETM-FABM-WET 三维水动力-水质-食物网耦合模型的**前处理工具**，用于可视化编辑模型的水下地形（bathymetry.nc）和出入湖河流配置（riverinfo.dat）。

---

## 启动方式

### 方式一：双击启动（推荐）
双击 `启动网格编辑器.bat` 文件。

### 方式二：命令行启动
```bash
cd C:\Users\dinod\Desktop\GETM-FABM-WET\3DWET\gui
C:\ProgramData\anaconda3\python.exe main.py
```

> 程序启动后会**自动加载理论湖案例**（24×20 网格，280 个水域格，5 条河流）。如需编辑其他案例，通过菜单 `文件 → 打开 bathymetry` 选择对应的 .nc 文件。

## 颜色含义

| 颜色 | 含义 |
|------|------|
| 棕色 | 陆地（bathymetry ≤ 0） |
| 浅绿 → 深蓝 | 水域，颜色越深表示水深越大（terrain 色标） |
| 蓝色半透明方块 | 入流河流（名称不以 OUT 开头） |
| 橙色半透明方块 | 出流河流（名称以 OUT 开头） |
| 黄色虚线框 | 当前笔刷影响范围 |
| 黄色边框 | 当前选中的单元格 |

## 工具详解（快捷键 1-6）

### 1. 平移工具（快捷键 1）
- **功能**：拖动鼠标平移视图
- **操作**：按住左键拖动，或按住中键拖动
- **滚轮**：以鼠标位置为中心缩放
- **提示**：任何工具下按住中键都可以临时平移

### 2. 绘制水深工具（快捷键 2）
- **功能**：点击或拖动设置水域格的水深
- **操作**：
  1. 在工具栏设置目标水深（默认 3.0m，范围 0.1-100m）
  2. 设置笔刷大小（1-20 格，`[` 减小，`]` 增大）
  3. 单击或拖动绘制
- **注意**：水深 > 0 为水域，绘制时会自动将陆地转为水域
- **黄色虚线框**实时显示笔刷覆盖范围

### 3. 切换水域/陆地工具（快捷键 3）
- **功能**：单击切换单元格的水域/陆地状态
- **操作**：点击水域格 → 变为陆地；点击陆地格 → 变为水域（使用当前平均水深）
- **支持笔刷**：可设置笔刷大小批量切换

### 4. 平滑工具（快捷键 4）
- **功能**：对单元格进行 3×3 邻域平均平滑
- **操作**：单击或拖动平滑水域格
- **全湖平滑**：左侧面板"平滑工具"→ 点击"对全部水域平滑"按钮，可设置迭代次数
- **注意**：只平滑水域格，陆地格不受影响

### 5. 添加河流工具（快捷键 5）
- **功能**：在水域格上添加入流/出流点
- **操作**：
  1. 在左侧面板或工具栏设置河流名称
  2. 点击水域格添加
- **命名规则**：
  - 名称以 `OUT` 开头 → 出流（橙色标记）
  - 其他名称 → 入流（蓝色标记）
  - 同名的多个格点属于同一条河流（多格河流）
- **预设名称**：INFL_NW, INFL_NE, INFL_W, OUTFL_S, OUTFL_E, INFL_1, OUTFL_1
- **注意**：河流只能添加在水域格上，添加到陆地格会被拒绝

### 6. 信息工具（快捷键 6）
- **功能**：查看单元格详细信息
- **操作**：鼠标悬停即可看到提示框，包含坐标、类型、水深、河流信息
- **提示**：任何工具下悬停单元格都会显示信息

在画布上**右键点击**任意单元格，弹出快捷菜单：

| 菜单项 | 功能 |
|--------|------|
| 网格 (i,j) 类型 水深 | 信息显示（不可点击） |

| 切换 水域/陆地 | 切换该格类型 |

| 在此添加河流... | 弹出对话框输入河流名称 |

| 适应窗口 (R) | 缩放至全图 |

## 文件操作

### 打开文件
- **Ctrl+O**：打开 bathymetry.nc（自动加载同目录下的 riverinfo.dat）
- **Ctrl+Shift+O**：单独打开河流文件

### 保存文件
- **Ctrl+S**：保存 bathymetry.nc（覆盖原文件，保留所有变量和属性）
- **Ctrl+Shift+S**：保存河流文件（riverinfo.dat）
- **另存为**：保存为新文件

### 新建网格
- **Ctrl+N**：创建空白网格，可设置：
  - X/Y 方向格数（2-500）
  - X/Y 方向格宽（米）
  - 初始水深（0 = 全部陆地，手动绘制水域）

---

## 编辑操作

### 撤销/重做
- **Ctrl+Z**：撤销上一步操作（最多 50 步）
- **Ctrl+Y**：重做
- 工具栏的撤销/重做按钮在不可用时会灰显

### 笔刷大小
- 工具栏数字框直接输入（1-20）
- 键盘 `[` 减小，`]` 增大
- 黄色虚线框实时预览笔刷范围

### 视图操作
| 操作 | 方式 |
|------|------|
| 缩放 | 鼠标滚轮 |
| 放大 | Ctrl++ |
| 缩小 | Ctrl+- |
| 适应窗口 | R 键 / 工具栏"适应"按钮 |
| 平移 | 平移工具下左键拖动 / 任何工具下中键拖动 |
| 取消选中 | Esc 键（同时切回平移工具） |

## 面板说明

### 工具选项（左侧）
- **绘制工具**：设置水深和笔刷大小（与工具栏同步）
- **河流工具**：选择/输入河流名称，提示命名规则
- **平滑工具**：设置迭代次数，一键全湖平滑

### 网格信息（右侧，标签页1）
实时显示：
- 网格尺寸（X × Y）
- 水域格数 / 陆地格数
- 最小/最大/平均水深
- 格网分辨率（米）
- 河流数量

### 河流列表（右侧，标签页2）
- 按名称分组显示所有河流
- 显示方向（入流/出流）、格点数、坐标
- 选中后点击"删除选中"可删除整条河流（需确认）

## 数据格式说明

### bathymetry.nc（NetCDF）
```
维度: x(列数), y(行数), xq(x+1), yq(y+1)
变量:
  - grid_type: 网格类型 (int)
  - x: X 坐标 (nx,) - UTM 米
  - y: Y 坐标 (ny,) - UTM 米
  - lonc: 经度 (ny, nx)
  - latc: 纬度 (ny, nx)
  - bathymetry: 水深 (ny, nx) - 正值=水域, 负值=陆地
```
> 保存时只更新 bathymetry 变量，其他变量和属性保持不变。

### riverinfo.dat（文本）
```
第一行: 河流格点总数
后续每行: i j name flag1 flag2
  - i: X 方向索引（1-based，即列号）
  - j: Y 方向索引（1-based，即行号）
  - name: 河流名称（同名多格=同一条河）
  - flag1, flag2: 标志位，通常为 -1
```

示例：
```
7
3 7 INFL_NW -1 -1
3 6 INFL_NW -1 -1
21 3 INFL_NE -1 -1
3 11 INFL_W -1 -1
13 19 OUTFL_S -1 -1
20 11 OUTFL_E -1 -1
20 12 OUTFL_E -1 -1
```

## 常见问题

### Q: 为什么河流添加不上？
A: 河流只能添加在**水域格**（bathymetry > 0）上。请先用绘制工具将目标格设为水域。

### Q: 保存后原文件的其他变量会丢失吗？
A: 不会。程序以 `r+` 模式打开 NetCDF，只更新 bathymetry 变量，x/y/lonc/latc 等变量和所有属性保持不变。

### Q: 笔刷最大只能 20 格吗？
A: 是的。对于大网格，建议先缩小视图，用较大笔刷绘制大致形状，再放大细化。

### Q: 撤销步数有限制吗？
A: 最多 50 步。拖动绘制的连续操作会合并为一次撤销。

### Q: 如何创建一个新湖泊的网格？
A: 
1. Ctrl+N 新建网格，设置格数和分辨率，初始水深设为 0（全部陆地）
2. 用绘制工具画出湖泊水域范围和水深
3. 用平滑工具修整水深过渡
4. 用河流工具添加入流/出流点
5. Ctrl+S 保存为 bathymetry.nc，Ctrl+Shift+S 保存 riverinfo.dat

### Q: 程序启动后白屏/无响应？
A: 请确认使用 Anaconda Python 3.10 启动。如缺少依赖，在 Anaconda Prompt 中执行：
```
pip install PyQt5 netCDF4 numpy scipy matplotlib
```
