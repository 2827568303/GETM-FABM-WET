### Step 2 — design references

No public comparable ranking establishes the objectively “best” company style for this scientific workbench. The design uses primary design-system sources as references, not as a global ranking:

- [Apple Human Interface Guidelines — Charts](https://developer.apple.com/design/human-interface-guidelines/charts): keep data visually prominent, use context-rich labels, and make chart interaction accessible. Adopt the chart-first hierarchy; avoid copying Apple-specific ornament.
- [Figma — Define your design system](https://help.figma.com/hc/en-us/articles/14552740206743-Lesson-2-Define-your-design-system): make accessibility, color, typography, and component dimensions shared foundations. Adopt semantic tokens for consistent dense scientific controls.
- [U.S. Web Design System — Design principles](https://designsystem.digital.gov/design-principles/): prioritize user goals, accessibility, and clear information order. Adopt keyboard reachability, legible contrast, and status cues that do not rely on color alone.
- [Esri Calcite — Components](https://developers.arcgis.com/calcite-design-system/components/): an established GIS system with purpose-built navigation, panels, filters, tables, and alerts. Use it as a domain-specific reference for recognizable GIS/workbench structures, not as a wholesale visual clone.
- [IBM Carbon — Data visualization color palettes](https://www.carbondesignsystem.com/building-blocks/data-visualization/color-palettes) and [color accessibility](https://www.carbondesignsystem.com/building-blocks/foundations/accessibility/color): distinguishes categorical from sequential palettes and warns against color-only communication. Adopt scientific gradients only for quantitative scales and pair status color with text/icon cues.
- [Microsoft Fluent 2 — Navigation usage](https://fluent2.microsoft.design/components/web/react/core/nav/usage/): recommends brief, plain-language navigation that can minimize to free space. Adopt short workflow groups and a collapsible rail that protects the result canvas.
