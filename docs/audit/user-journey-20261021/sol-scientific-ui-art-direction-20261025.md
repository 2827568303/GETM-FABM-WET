# Sol（GPT-6.1）科研工作台 UI 艺术指导

日期：2026-10-25  
范围：全局导航与工具区、工作台、表单、卡片、图标及科学可视化边界。

## 设计判断

当前产品适合定位为“水环境研究工作台”，不是营销型 SaaS，也不是纯黑白论文排版。界面要安静、精确、可长时间阅读；颜色负责空间分区和状态识别，科学变量色带与模型场景继续承担定量表达。

采用暖纸白、石灰灰、雾蓝灰、低饱和灰绿作结构色；通过明度、细边线和少量留白建立层次。活动导航和工具状态用低饱和湖蓝/灰绿，黄色系只用于提示，红色只用于错误。除科学图层/模型结果外，不以高饱和色作装饰。避免纯黑白单色、彩色渐变、厚重阴影、胶囊堆叠和大面积强调色。

全局布局按研究任务组织：左侧稳定的工作流导航，中部最大面积给数据与模型，右侧检查器收纳参数和图层，顶部工具带只放当前上下文的高频动作。首屏不堆大标题/宣传文案；尽量让用户先看到活动案例、数据状态和模型视图。控制密度依赖对齐、分组和标签层级，不依赖艳色卡片。

图标统一为单色、几何、光学尺寸一致的线性符号：约 1.6–1.8 px 视觉笔画，统一 24 单位网格和端点/转角处理。优先用地图、网格、剖面、层片、时间序列、仪器读数等领域符号；不用表情、拟物生物角色、装饰性彩色徽章或粗圆角卡通图案。图标颜色继承文字/状态色，静态导航图标保持中性，只有当前选择与语义告警改变颜色。

## 艺术总监取舍

1. **保留颜色，但降低装饰饱和度。** UI 结构层采用一组暖中性 + 灰绿/雾蓝；模型变量色带仍按数据类型选用可读的定量色带，不为界面统一而牺牲科学区分度。
2. **强化工作台而非仪表盘装饰。** 让模型/图表获得最大对比和面积，卡片、导航、按钮退到背景；状态依赖短文本、符号和有限语义色，而非颜色单独传意。
3. **图标从“可爱”改为“仪器化”。** 统一线宽、格点和构图语法，减少绘画性弯曲和拟物；每个符号可在 16–24 px 下识别，避免导航靠混合 emoji/外部图库。
4. **不牺牲密度与可发现性。** 科研用户需要高频查看坐标、单位、时间、层号与质量状态；采用紧凑排版和分组，不把关键数据藏进纯图标按钮或悬浮菜单。
5. **明确垂向显示与科学语义。** 体网格、三角化和垂向夸张属于可视化编码，必须贴近控件解释；它们不能暗示求解器原生三角拓扑、水平分辨率提升或生态物理迁移。

## Sol 对当前实现的验收关注点

- 界面代码整体应使用上述色彩关系，不得只把一块局部面板改成学术色；页面、导航、按钮、表单、通知和对话框都需一致。
- 有色状态只限于模型数据色带和必要语义状态；所有图标统一为成熟的几何线性符号。
- 源码/自动化截图或测试通过只能算**代理**。若 52812 首页仍引用缓存模板、或桌面 shell 没有载入当前静态资源，则整体 UI 的桌面视觉交付仍**未完成**。
- 3D 体网格预设的代码回归不等于视觉体验确认；需要在现有桌面窗口载入最终源码后检查纵深、图例与面片边界。

- 参考资料：**实测（官方手册页面已读取）**。
