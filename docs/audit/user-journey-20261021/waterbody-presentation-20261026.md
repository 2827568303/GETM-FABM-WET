## 艺术指导依据

- [Nature Research Figure Guide](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)：明确轴与单位、保持图例可读、使用无障碍色板并减少装饰；采用这些原则来保留水深定量色标和清晰状态标签。
- [Nature Scientific Data 的 3D-LAKES 论文](https://www.nature.com/articles/s41597-025-05911-y)：展示全球湖库三维测深数据产品，并记录产品来源和不确定性；采用“真实几何需要可追溯输入”的原则，不把平滑湿网格边界说成同等精度的数据产品。
- 艺术总监取舍：保留定量蓝青色深度投影、明晰单位和等深线；去掉静态预览里无高程依据的干格方块；仅软化显示边界以减弱方格感。该改动优先保证科学语义和可读性，不添加虚构地形或装饰性水波。
