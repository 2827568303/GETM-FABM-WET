# Erken 模型输出覆盖盘点

**负责人：Sol 高**  
**状态：代理资料盘点；不是科学验证。**

## 范围与方法

只读扫描当前 `build/` 下路径包含 Erken、文件名为 `*.3d.nc` 的 NetCDF 模型输出。对每个可读文件检查 `time` 变量长度及首末时间戳。`meteo.nc`、`rivers.nc` 等气象和河流强迫输入不计作模型输出。本次没有创建、运行、删除、清理或覆盖案例，也没有打开或刷新应用窗口。

## 结果

- 共找到 127 个 Erken 名称的 `*.3d.nc` 文件；91 个有非空时间轴，34 个时间轴为空，2 个不可读。
- 本次盘点找到的最长非空模型输出为 168 个小时帧，时间从 2024-06-13 14:00 到 2024-06-20 13:00（七天）。多个 A/B/C 候选或旧版输出覆盖同一时段。
- 现有观测配对报告使用 168 个模型帧 × 50 个观测深度，共 8,400 对；模型值来自候选求解器输出，且强迫和初始条件有限制，详见单独的配对审计记录。
- 较广泛 NetCDF 清单里较长的 2020 文件是 `meteo.nc` / `rivers.nc` 强迫输入，不能作为更长模型模拟的证据。

## 状态与限制

- **代理**：现存七日候选求解器诊断及其观测配对分析。
- **未完成**：Erken 季节/长期科学验证，以及 Erken、Lake Ravn、Bryrup、Arreskov 四个案例的完整用户流程。
