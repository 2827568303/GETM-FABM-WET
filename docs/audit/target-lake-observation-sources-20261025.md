This note records authoritative source metadata found during follow-up. Source existence and metadata are not equivalent to local download, schema mapping, run reproduction, or scientific validation.

## Erken

- **实测（来源元数据核查）**: SITES metadata identifies a downloadable daily anchored temperature-profile CSV for Lake Erken, 2012-05-11 through 2012-09-22, with columns from 0.5 to 15 m and a CC BY 4.0 license. Source: [FEMC Erken Raw Sonde Data](https://www.uvm.edu/femc/data/archive/project/geisha-stormblitzfr/dataset/erken-raw-sonde-data/overview).
- **未完成（case validation）**: These records do not by themselves establish that their raw files have been downloaded, quality-screened, mapped to model output depths/times, or used in an independent validation split for the target GETM 3D case. Existing Erken proxy forcings and outputs remain **代理**.

## Lake Ravn

- **实测（来源元数据核查）**: The current Aarhus University WET cases page describes Lake Ravn as monitored under Denmark's national program since 1989 and links a full GOTM-WET test case with calibration inputs. Source: [WET Lake Ravn case page](https://projects.au.dk/wet/cases).
- **未完成（target application validation）**: The official upstream run already recorded in [STATUS.md](user-journey-20261021/STATUS.md) is a 1D GOTM-WET run, not the target GETM 3D application. It also has observation-variable name mismatches, missing total-N/total-P units, and many FABM interior state repairs. Do not treat the upstream execution or its data package as scientific validation of the target app.

## Bryrup

- **实测（literature metadata核查）**: WET 1.0 reports monthly-to-semi-monthly observed water temperature, dissolved oxygen, NO3, NH4, PO4, total N, total P, and chlorophyll-a from NOVANA. That study's calibration/validation configuration is documented in the existing case audit; it is a 1D GOTM-WET study, not validation of this target GETM 3D case. Source: [WET 1.0 paper](https://gmd.copernicus.org/articles/15/3861/2022/).
- **实测（official monitoring summary）**: The Danish agency's Bryrup Langsø page locates the monitoring station in the lake's deepest area and says water/plankton samples plus temperature and oxygen profiles are collected there. It reports 19 sampling events per year every other year from 2015 onward, with annual sampling from 1989–2015. The page says its overview plots include recent 2025 observations, are updated monthly, and may contain results that have not completed quality assurance. Source: [SGAV Bryrup Langsø monitoring guide](https://sgavmst.dk/natur-og-jagt/naturen-i-danmark/novana-overvaagning-af-natur-og-vandmiljoe/guider-til-danske-vandomraader/soe/bryrup-langsoe).
- **Source limitation**: This page provides monitoring context and summary plots, not the station-level, depth/time observation rows needed for a reproducible numerical match. An older STOQ guide identifies Bryrup Langsø with lake number 90930; do not assume that legacy identifier maps directly to a current VanDa station ID without a crosswalk.
- **实测（catalog metadata核查）**: Denmark's Arealdata catalog lists the lake-water-chemistry VanDa dataset as a CSV extract, with a CC0 license on the catalog record. Source: [VanDa lake water chemistry dataset](https://arealdata.miljoeportal.dk/datasets/urn:dmp:ds:vandkemi-soe).
- **实测（access check）**: An unauthenticated ranged GET to the catalog's CSV endpoint (`https://arealdata-api.miljoeportal.dk/data/vanda-ue-26/file`) returned HTTP 401; no CSV bytes were retrieved. This proves only that this direct request was unauthorized in the current environment; it does not establish whether the portal's browser download flow can provide access. Danmarks Miljøportal's separate VanDa system guide describes organization/MitID sign-in ([VanDa access guide](https://support.miljoeportal.dk/hc/da/articles/4414100712081-VanDa-Vandkemi)), but that is not evidence that this CSV endpoint requires the same login. No user credentials were requested or used.
- **未完成（data linkage and validation）**: The current record does not prove the historical Bryrup observation rows have been downloaded from VanDa/ODA, joined to the correct lake station and variables, or matched to this target model's output. The known station/source and observation pairing gap remains open.
- **实测（published 1D model-observation comparison; not target-app validation）**: DCE Report 402 compares daily full-water-column observations with the 1D GOTM-FABM-PCLake model. It defines 1990–1995 as warm-up, 1996–2003 as validation, and 2004–2005 as calibration. Reported validation statistics include temperature R² 0.98 (BIAS −4.0%), dissolved oxygen R² 0.41 (BIAS +9.5%), and chlorophyll-a R² 0.39 (BIAS −55.0%). The large chlorophyll bias is an explicit limitation; these published 1D statistics are context only and do not validate this target 3D application. Source: [DCE Scientific Report 402](https://dce.au.dk/udgivelser/vr/nr-401-450/abstracts/no-402-dynamic-process-based-models-as-a-management-tool-for-danish-lakes) (full report: [PDF](https://dce2.au.dk/pub/SR402.pdf)).
- **实测（published setup distinction）**: WET 1.0 is a separate 1D Bryrup study. Its paper reports six spin-up years, calibration in 1996–2004 and validation in 2004–2006, and monthly-to-semi-monthly NOVANA observations; it says the observations are stored in ODA and points to ODA for all. This period split is distinct from DCE Report 402's Bryrup configuration above; do not merge their splits or metrics. Source: [WET 1.0 paper](https://gmd.copernicus.org/articles/15/3861/2022/).
- **实测（access check）**: Opening the cited [ODA for all portal](https://odaforalle.au.dk/) redirected to `login.aspx`; no data were downloaded. Danmarks Miljøportal's current VanDa guide says access to the VanDa system is through organization login, and its roles page describes a VanDa read role. These checks show the public observation rows are not yet locally available through the attempted unauthenticated routes; they do not establish which organization role or request path will grant access to this project's user. Sources: [ODA for all](https://odaforalle.au.dk/), [VanDa guide](https://support.miljoeportal.dk/hc/da/articles/4414100712081-VanDa-Vandkemi), [VanDa roles](https://support.miljoeportal.dk/hc/da/articles/360000292978-Roller-Overfladevand-VanDa).

## Arreskov

- **实测（literature metadata核查）**: The 2022 Arreskov study documents lake monitoring since 1989, including roughly 19 in-lake samples per year for nutrients and chlorophyll-a, temperature and dissolved-oxygen profiles, plankton sampling, and historical tributary flow/nutrient records. Source: [Andersen et al. 2022 paper](https://doi.org/10.1016/j.envsoft.2022.105501).
- **实测（catalog metadata核查）**: The same official VanDa lake-water-chemistry catalog entry is a candidate public source for Danish lake chemistry rows. Source: [VanDa lake water chemistry dataset](https://arealdata.miljoeportal.dk/datasets/urn:dmp:ds:vandkemi-soe).
- **实测（access check）**: The direct ranged CSV request returned HTTP 401 without authentication, and no data rows were retrieved. See the access limitation recorded under Bryrup. This leaves the candidate dataset's station mapping and Arreskov rows **未完成**.
- **未完成（configuration/data linkage and validation）**: The VanDa catalog entry does not resolve the missing matching WET `fabm.yaml`, target-model configuration, data station mapping, or calibration/validation split. Prior archive checks remain inconclusive about whether another release/supplementary package contains the matching files.
- **实测（published 1D model-observation comparison; no independent holdout）**: DCE Report 402 states that Arreskov's warm-up was shortened to 1990–1992; all post-warm-up observations through 2004 were used in calibration to include observed abrupt state shifts, so no separate validation period was defined. Its 100-member ensemble reported temperature R² 0.98–0.99 and BIAS +0.6% to +3.2%, while chlorophyll-a R² ranged 0.07–0.11 and BIAS −51.9% to +21.3%. The report also says the ensemble did not reproduce abrupt shifts between algal and submerged-vegetation states. This is a published 1D comparison with observations, not an independent test and not validation of this target 3D application. Source: [DCE Scientific Report 402](https://dce.au.dk/udgivelser/vr/nr-401-450/abstracts/no-402-dynamic-process-based-models-as-a-management-tool-for-danish-lakes) (full report: [PDF](https://dce2.au.dk/pub/SR402.pdf)).
- **实测（published data provenance; access still unresolved）**: The Arreskov paper describes a comprehensive 12-year dataset used in the 1D ensemble study, but this literature statement does not provide the matching target-app input/observation files. The same DCE/VanDa/ODA access limitations recorded under Bryrup apply. Source: [Andersen et al. 2022](https://doi.org/10.1016/j.envsoft.2022.105501).
- **实测（published calibration design and archive audit）**: The paper states that GOTM-WET was calibrated over 1992–2005 using the full dataset with no validation period, and says its configuration was included as a WET test case. A separate archived audit checked the cited v0.1.0 package and all publicly advertised/retrievable refs of the current WET repository but did not recover the matching `fabm.yaml`, calibrated ensemble, or raw observation bundle. See [Arreskov source/reproduction audit](../../build/academic-case-validation-20261022/arreskov-source-audit/AUDIT.md). This is a reproducibility gap in recovered materials, not evidence that no private or unadvertised author archive exists.

## Erken independent benchmark-source lead — 2026-10-25 continuation

- **实测（来源元数据）**: CUAHSI HydroShare record 10.4211/hs.ace98c3bc72b44f1834a58ec8b3af310 describes a public Lake Erken GOTM temperature package containing separated calibration data (2006–2014) and validation data (2015–2016): hourly/daily meteorological forcing, observed daily temperature profiles, configuration files, calibration settings, and outputs. The package is CC BY 4.0 and 34.2 MB. Source: https://www.hydroshare.org/resource/ace98c3bc72b44f1834a58ec8b3af310/ .
- **Interpretation**: this is a materially better reproducibility lead than a short uncalibrated window because it supplies an explicit held-out period and reference implementation. It is a 1D GOTM benchmark; it cannot by itself validate the target 3D GETM/WET application or ecological behavior. A target 3D comparison would still need a documented mapping of forcing, bathymetry, spatial station representativeness, initialization, and observation depths/times.
- **未完成**: the resource files were not downloaded or adopted. The source page presents a license-confirmation step before download; no acceptance was performed. No model run or case creation occurred. Erken science remains **未完成**, with prior proxy output and measured-observation comparison classifications unchanged.
