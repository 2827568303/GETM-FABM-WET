# 界面语言与语言包

菜单栏点击「语言」，在独立窗口中选择中文或 English，预览后点击「应用」。菜单、操作按钮、模型变量、参数及科学说明只显示所选语言，不强制中英并列；变量代码、数值和单位保持原样。选择与已应用的语言包保存在模型目录 `.studio-runtime/language.json`，桌面重启、切换端口后仍有效；浏览器另保留本地缓存。

同一窗口提供「下载语言包模板」与 JSON 文件导入。模板使用中文原文作为键，翻译作为值，保留 `{count}` 等占位符：

```json
{"locale":"fr-FR","name":"Français","messages":{"取消":"Annuler","应用":"Appliquer","仪表盘":"Tableau de bord"}}
```

`locale` 必须是有效语言标记，例如 `fr-FR`、`de-DE`、`ja-JP`；`zh-CN` 和 `en-US` 为内置保留语言。缺少的导入词条优先使用内置英文，仍未知的内容保留原文。模型变量的名称、解释与参考依据按中文/英文元数据切换，其他语言包可覆盖对应中文词条。

每个文件最大 256 KiB，最多 4000 个纯文本词条，最多保存 16 个外部语言包。不接受 HTML、脚本、原型污染键或无效语言代码。导入只读取本机文件，不调用在线翻译。技术变量编号、数值、单位、路径、配置代码、求解器原始日志及用户输入保留原样。
