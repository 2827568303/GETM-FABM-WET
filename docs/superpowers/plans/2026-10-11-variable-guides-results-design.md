# 变量说明、基准比较与结果管理实施计划

用户要求直接改进二维/三维变量理解、参考值、结果保存及清理和模型样式。

采用共享变量元数据服务：中文名称、原始编号、定义、单位、参考来源。经核实的水质标准仅用于同一指标和可比单位；模型初始值用作变化参考，不作为健康阈值；无通用阈值的过程量提供明确说明及用户设定入口。

结果管理只列出当前案例的已知产物，显示绝对路径，按字节哈希识别重复项。用户选择后移入可恢复回收区，再单独清空；校验路径、输入保护、运行/率定状态及清单版本。不会自动清理运行结果。

展示参考官方 QGIS 3D 与 Delft3D QUICKPLOT，改善统一科学色阶、岸线、坐标和色标，保留真实湿网格、水深及缩放交互。
