# QGIS 风格 UI 实施计划

## 任务 1：增加工作台骨架

在 `index.html` 的主内容区增加菜单条、快捷工具条和底部状态栏；为状态栏补充案例与运行状态同步钩子，保持原有页面 ID 和导航不变。

## 任务 2：覆盖 QGIS 视觉层

在 `studio.css` 追加 QGIS 风格主题层：中性灰画布、深灰停靠面板、紧凑间距、扁平按钮、细边框、工具条状态、表格/日志/图层/诊断样式与移动端适配。

## 任务 3：验证与打包

扩展主题契约测试，运行全量 Python/JavaScript 测试；启动网页端进行静态资源和 API smoke test；重新构建桌面程序和安装包，运行安装后自检。
