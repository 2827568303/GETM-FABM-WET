# 3DWET Studio 湖泊工作台视觉设计

## 目标

把现有 3DWET Studio 的界面统一成适合长时间建模工作的“湖泊工作台”风格：深海蓝导航、雾白内容区、湖水青绿色强调色，改善层级、间距、状态反馈和图形容器的观感，同时保持现有页面、控件 ID、交互和桌面/Web 两种入口不变。

## 现状与约束

- `style.css` 提供基础布局和深色主题；`studio.css` 是当前统一视觉覆盖层。
- 页面结构集中在 `index.html`，大量页面依赖既有 class 和稳定的控件 ID。
- 运行控制、诊断、网格编辑和三维视图已经有独立功能，视觉改造不能改变其数据流和事件绑定。
- Ctrl+滚轮界面缩放由 `view_controls.js` 管理，主题样式需要在 60% 到 180% 比例下仍保持可读和可操作。

## 视觉方向

### 色彩

- 导航：`#0b2538` 到 `#123c4e` 的深海蓝；当前项使用湖水青绿色渐变。
- 内容背景：`#f4f8fb`；卡片：半透明白色配细边框。
- 强调色：`#0b8f8c`；悬停和焦点使用更深的青绿色。
- 状态色：成功使用青绿，警告使用琥珀，错误使用珊瑚红，运行中使用蓝绿脉冲。
- 阴影保持低对比，避免大面积发光和高饱和渐变。

### 布局与层级

- 侧栏增加清晰的品牌区、分组标题和当前项指示条。
- 顶部栏使用轻微玻璃质感，案例徽章和运行状态成为主要上下文信息。
- 页面标题、说明、卡片标题形成稳定的字号梯度。
- 统计卡片、工作流条、诊断面板和图表容器使用相同的圆角、边框和悬停规则。
- 表格表头固定、行悬停明显，表单焦点统一为湖水色边框和浅色光晕。

### 图形与运行反馈

- Plotly、Chart.js、Leaflet 和 Canvas 的外层容器统一白色卡片和工具条样式。
- 运行日志维持深色终端风格，成功、警告和错误行有明确颜色。
- 空状态使用浅色插画感容器和更短的提示文本，不改变现有内容。
- 全屏图形和 60%/180% 界面缩放仍保持边距、按钮和文本不溢出。

## 非目标

- 不更换前端框架，不重写页面结构。
- 不改变模型计算、API、输出文件、诊断逻辑或控件 ID。
- 不删除已有主题变量；新规则集中在 `studio.css`，便于回滚。

## 验收标准

1. 首页、案例管理、运行控制、交互网格、诊断和三维页面使用一致的视觉语言。
2. 当前导航、案例徽章、运行状态和主要按钮在截图中一眼可辨。
3. 表单、表格、诊断操作和图形工具条在浅色背景上有足够对比度。
4. 普通浏览器窗口、WebView 窗口以及 Ctrl+滚轮缩放后没有水平溢出或不可点击控件。
5. 现有 Python/JavaScript 回归测试和浏览器烟测保持通过。
