# 分层导航、可组装生态网络与实测率定案例（委托定稿）

## 推荐方案与取舍

推荐“分层工作流菜单 + 模型实例组装器 + 同湖实测率定示例”。初次打开只显示五个主入口，点开后才显示下一层功能，专家仍能直接搜索功能。另一方案是严格逐步向导，但不利于反复调整和专家跳转；仅折叠现有长列表改动小，却不能清晰区分水质和生态，也不能解决实例固定的问题。

## 左侧导航

1. 项目：概览、案例、新建/导入、已有实测案例。
2. 数据与网格：边界和测深、气象和河流、交互网格、点位。
3. 模型配置：物理、水质、生态、初始条件、时间与输出。水质下分营养盐/溶氧、有机物、沉积物、碳与气体；生态下分藻类、浮游动物、底栖动物/双壳类、水生植物、鱼类、关系网。
4. 计算：运行、检查与修复、运行记录。
5. 结果与率定：地图、二维、三维与剖面、时序与垂向热图、观测管理、率定比较、自动率定、结果文件与恢复。

设置/帮助为底部次要入口。默认只展开活动分组，保留当前案例、运行状态、键盘访问、窄屏抽屉、语言切换；原功能逐项映射，不以隐藏不可达功能换取简洁。顶栏常用工具保留。

## 水质与生态配置

分成两个独立用户入口和实例目录，底层仍为同一个FABM耦合模型：营养盐、氧、碳和生物量交换保持原有守恒关系。水质过程的启用状态、参数和初值独立管理；生态按功能群管理多个真实实例。

生态添加流程：选功能群类型/现有实例模板 → 设唯一引用名和显示名 → 编辑性状、参数和初值 → 选实际耦合目标 → 预览受影响关系 → 保存并校验。藻类和鱼类可以添加多组、复制、重命名和可恢复删除；鱼类支持食性和生活阶段的显式关系。显示名可以使用具体物种名，参数模板明确其为起点，不能宣称已针对该物种率定。

关系网的连线必须写入实际FABM端口，允许增加猎物/食物耦合和相应参数；预览明确源实例、目标状态变量、过程与单位，不能只画一条不起作用的线。新增/删除实例同时更新相关汇总计算器、初始化文件、输出订阅和变量说明，拒绝悬空引用与重复名称，运行中禁止更改；原YAML无关字段保留、过期配置拒绝、每次事务备份。

## 集中修复和验证

继续先完成当前版本的剩余诊断，收齐回弹、微秒时间/配对、真实深度、图表对比度、小数步长输出核验等问题，再集中实施。新增工作分别有独立回归：所有旧导航入口可达；新增两个藻群和两个鱼群并建立关系，实际模型输出各自状态量且重载/重启保持；水质和生态入口及耦合一致；真实观测文件夹导入、深度/单位/时间匹配、优化、应用与恢复。

更新桌面安装版并固定源码/求解器/资源指纹后，用五套不同新数据各自从上传到构建、完整真实运行、所有功能组和最终产物连续通过五轮。任一完整轮次失败清零。官方已有观测示例另做完整科学验证，不冒充五套新数据或已有五次通过。
