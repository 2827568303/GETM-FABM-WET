# QGIS 风格工作台 UI

## 目标

让 3DWET Studio 的网页端和 Windows 桌面端采用 QGIS 式 GIS 工作台语言：紧凑工具区、停靠面板、浅灰画布、扁平控件和明确的状态栏，同时保留现有页面、稳定 ID、模型接口和交互逻辑。

## 设计

- 在主工作区顶部增加菜单条和工具条，提供项目、编辑、视图、图层、运行、设置、帮助等入口，以及案例、网格、运行、地图、2D、3D 的快捷按钮。
- 将现有深色侧栏压缩为 QGIS 风格的导航停靠面板，保留所有 `data-page` 页面入口和当前页高亮。
- 将内容区、卡片、输入控件、表格、诊断面板和可视化容器改为浅灰底、细边框、低圆角、紧凑间距；地图/网格画布使用中性灰与深色图层底。
- 在主区域底部增加状态栏，展示当前案例、运行状态、网格状态和视图缩放信息，并由已有案例/运行状态逻辑同步更新。
- 在 760px 以下保留响应式布局，工具条可横向滚动，侧栏和状态栏不遮挡现有页面。

## 约束与验证

- 不更改模型计算、API、稳定 DOM ID 或已有页面导航行为。
- 浏览器端和桌面端继续共享 `index.html`、`style.css`、`studio.css` 和 `app.js`。
- 使用主题契约测试、全量 Python 测试、JavaScript 语法/可视化测试，并通过网页端 HTTP smoke test 验证核心静态资源和 API。
