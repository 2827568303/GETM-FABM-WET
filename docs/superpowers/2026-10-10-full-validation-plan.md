# 湖泊工作台完整验证与展示改进

用户已授权直接修改网页与 Windows 桌面版，沿用已确认的 QGIS 风格。

## 验收范围

1. 修复原生求解器随机崩溃，以同一骆马湖输入重复运行验证。
2. 每一个内置案例在隔离目录运行至少 20 分钟模型时间；核对输入、预检、真实求解、结果文件、时间终点和湿网格数值。
3. 固定随机种子生成外部边界、测深、气象、河流与观测数据，走真实上传、建模、导入、求解和结果接口。
4. 验证结果图、剖面、监测点、生态网络、鱼类、温室气体、率定与导出；无法适用的功能明确注明。
5. 用“年份 + 年内儒略日（DOY）”呈现界面日期，内部继续使用求解器需要的 ISO/CF 时间。
6. 参考 QGIS 3D 与 Delft3D 官方展示，使用真实湿网格、等深线和色标改善湖盆视觉，不生成虚假地形。
7. 统一测试源码与打包 Windows 程序，随后生成安装包。

## 判断标准

不能把进程退出码零、空输出目录或前端状态完成单独视为通过。必须存在多帧结果、结束时间正确、关键水动力场有效、所有扫描输出数值有限。短时集成通过仅证明所测运行窗口与操作链路正常，不能替代真实观测率定或长期科学验证。

## 已定位问题

原生调用栈进入 `ip_blumberg_mellor_lin`。σ 与一般坐标没有初始化该算法使用的 `kmin_pmz/kumin_pmz/kvmin_pmz`，自适应坐标已初始化。修复统一的无部分底层坐标下界；移除缺乏证据的 HDF5 文件锁规避。
