Shortcut keys in Main Form

    Model: 
    Ctrl+N New Model:
    Hold CTRL key and press N key to create new model.
    Ctrl+O Open Model:
    Hold CTRL key and press O key to open a model.
    Ctrl+S Save Model:
    Hold CTRL key and press S key to save the model.
    Ctrl+Alt+S Save As Model:
    Hold SHIFT and ALT key and press S key to save as the model.

    Shortcut keys in 3D View

      Key strokes for changing view of the 3D View window: 
      Escape End animation
      Press the Escape key to end current animation process.
      Ctrl+E Zoom to full extents
      Hold CTRL key and press E key to view full extent of all layers.
      Alt+E Export the current plot to a bitmap file.
      A Move camera left
      Press Left Arrow key or D key to move the camera left.
      D Move camera right
      Press Right Arrow key or D key to move the camera right.
      R Move camera up
      Press R key to move the camera up.
      F Move camera down
      Press F key to move the camera down.
      S Move camera backward
      Press Down Arrow key or S key to move the camera backward.
      W Move camera forward
      Press Up Arrow key or W key to move the camera forward.
      Up Arrow Move camera forward
      Press Up Arrow key or W key to move the camera forward.
      Down Arrow Move camera backward
      Press Down Arrow key or S key to move the camera backward.
      Left Arrow Move camera left
      Press Left Arrow key or D key to move the camera left.
      Right Arrow Move camera right
      Press Right Arrow key or D key to move the camera right.
      F5 Refresh the window
      Press F5 key to redraw the current window.
      F4 Show/Hide Form border, time control, status bar
      Press F4 to show/hide Form border, time control, status bar.
      Mouse controls
      Shift+RMC Pan
      Hold SHIFT key and use the right mouse button to shift the view.
      RMC Rotate
      Use the right mouse button to rotate the view.
      Mouse Wheel Change zoom factor
      Scroll the mouse wheel up or down to change the zoom.
      Shift+[ (Open Brackets)Increase Legend Font 
      Shift+] (Close Brackets)Decrease Legend Font 
        Key strokes for changing time of the 3D View window 
        Home Go to the first time step 
        End Go to the last time step  
        PgUp Go backward 1 time step 
        PgDn Go forward 1 time step 
        Shift+PgUp Go backward 10 time steps 
        Shift+PgDn Go forward 10 time steps 
        Ctrl+PgUp Go backward 100 time steps 
        Ctrl+PgDn Go forward 100 time steps 
        Ctrl+G Go to a specific time 
          Other key strokes 
          F7 Toggle Julian Dates 
          Alt+L Load settings from file 
          Alt+K Save settings to file  
          Other shortcuts 
          Ctrl+F2 Open shortcut key list:
          Hold CTRL key and press F2 key to open shortcut key list.
          Ctrl+A Restore up model control form:
          Hold CTRL key and press A key to restore up model control form.
