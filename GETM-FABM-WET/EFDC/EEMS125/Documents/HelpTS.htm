  • Key strokes for changing view of the Time Series window

      Key strokes for changing view of the Time Series Plot window 
      + Zoom in:  Press + key to zoom in.
      - Zoom out: Press - key to zoom out.
      Ctrl+E Zoom to full extents: Hold CTRL key and press E key to view full extent.
      Mouse Wheel Change zoom factor:  Scroll the mouse wheel up or down to change the zoom.
      F5 Refresh:  Press F5 key to redraw the current window.
        Key strokes for Panning window 
        Up Move the series up 
        Down Move the series down 
        Left Move the series left 
        Right Move the series right 
        Other key strokes 
        F7 Toggle julian dates 
        Alt+L Load settings from file 
        Alt+K Save settings to file 
        Ctrl+C Show lines as CDF's 
        Ctrl+S Display line statistics by time blocks 
        Ctrl+A Compute the averages for the time series 
        Ctrl+B View box-whisker plot 
        Ctrl+I Integrate the time series 
        Ctrl+L Compute the % of time the Y values less than a specified level 
        Ctrl+N Toggle the moving averages 
        Ctrl+W Set the ViewPort to a specific size 
        Ctrl+X Use last edited axis for all 
        Ctrl+[ (Open Brackets) Increase Axis Font 
        Ctrl+] (Close Brackets) Decrease Axis Font 
        Shift+[ (Open Brackets) Increase Legend Font 
        Shift+] (Close Brackets) Decrease Legend Font
